# NOTES

## Optional: `?.`, `??`, `if let`

- `?.` (optional chaining) — если слева `nil`, вся цепочка становится `nil`, ничего не падает.
- `??` (nil-coalescing) — если слева `nil`, берёт значение справа; результат уже не Optional.
- `if let x = optional { ... } else { ... }` — то же самое, но явно и многословно: если значение есть, разворачивает его в `x`, иначе — `else`.

## Цикл SwiftUI

`@State` (следи за значением) → `$` (право записи) → `body` (как выглядит экран). Меняется состояние — `body` вызывается заново целиком. Экран не «обновляют» вручную, его описывают для каждого состояния.

- `List` со `selection:` пишет в биндинг `id` выбранной строки (тип `Game.ID?`), а не саму строку — потому что данные `Identifiable`.

## Тип vs экземпляр

`ИмяТипа()` — создаёт экземпляр (реальный объект в памяти). Методы вызываются у экземпляра (`store.del(...)`), а не у самого типа (`GameStore.del(...)` не работает, если метод не `static`).
