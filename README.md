# GameGraph

**Личная коллекция видеоигр и карта связей между ними.** Учебное приложение для macOS на Swift и SwiftUI.

Записывай, во что играл, сколько времени провёл в игре и что хочешь пройти дальше. Идея GameGraph — показать, как игры из твоей коллекции связаны между собой. У каждой игры будет свой узел, а линии между ними покажут общий жанр, студию, издателя, серию или тег.

## Текущее состояние

В репозитории есть интерфейс каталога с боковым списком, карточкой игры и формой добавления и редактирования. В форме предусмотрены год выпуска, жанры, теги, разработчик, издатель, серия, статус и часы игры. Там же можно выбрать изображение обложки с диска.

Приложение рассчитано на ручное ведение коллекции и работу офлайн. Игровые записи хранятся в `~/Library/Application Support/GameGraph/games.json`, а обложки — отдельно в папке `covers/`. Для чтения и записи используется `Codable`. Проект использует системные фреймворки Apple.

> **Статус `main`.** В ветке остались два объявления `ContentView`, а исходники `Game` и `GameStore` отсутствуют. Сначала нужно завершить перенос файлов и восстановить сборку.

## Дорожная карта

| Этап | Что должно получиться |
| --- | --- |
| **1. Восстановить сборку · следующий шаг** | Вернуть `Game` и `GameStore`, оставить один `ContentView` и проверить запуск на чистом профиле, сохранение после перезапуска и работу с обложками. |
| **2. Добавить поиск, фильтры и сортировку** | Искать по названию, фильтровать по статусу, жанру или тегу и сортировать по названию или году. |
| **3. Построить граф связей** | Вычислять связи из полей каталога и строить раскладку, в которой связанные игры притягиваются друг к другу. Дать пользователю выбор, какие типы связей показывать. |
| **4. Сделать граф интерактивным** | Подсвечивать соседние игры при наведении, открывать карточку по клику, поддержать масштабирование и перемещение по карте. |

Ближайшая цель — собрать полностью локальный каталог с интерактивным графом. Импорт из Steam отложен.

## Запуск из исходников

В проекте указан минимальный таргет **macOS 26.5**. Для запуска после восстановления сборки открой [`Games_Graph.xcodeproj`](Games_Graph.xcodeproj) в Xcode, выбери схему `Games_Graph` и устройство **My Mac**, затем нажми **⌘R**.
